# Костанай · микрорайон «Юбилейный»

Территория: Казахстан → Костанайская область → город Костанай → микрорайон «Юбилейный».

Центр: 63.613424° E, 53.243136° N. Местоположение проверено по [карточке района Яндекс Карт](https://yandex.kz/maps/ru/10295/kostanai/geo/yubileynyy_yqsham_audany/2064931254/). Для трассировки использованы исключительно данные OpenStreetMap.

## Исходные данные

- Контур жилого района: [OSM way 657304160](https://www.openstreetmap.org/way/657304160), название «ЖК Юбилейный». Это ориентир жилого района, а не утверждённая административная или кадастровая граница.
- Снимок дорог, проездов и зданий: `data/geography/kostanay-yubileyny-osm.json`, получен через `https://overpass-api.de/api/interpreter`. Время базы OSM: 2026-10-11T04:19:34Z.
- Ограничивающий прямоугольник запроса: south=53.235, west=63.600, north=53.251, east=63.625. Дополнительно получены именованные объекты «Юбилейный» в окружающей области.
- © OpenStreetMap contributors. Географические данные и производная геометрия распространяются по [ODbL 1.0](https://www.openstreetmap.org/copyright). Атрибуция отображается на карте и сохранена в метаданных модели.

## Построение

1. Дороги и автомобильные проезды обрезаются по контуру с полосой 30 м для охвата периметральных дорог. Пешеходные дорожки и парковочные ряды не используются как магистрали.
2. Пересечения сохраняются по общим узлам OSM. Выбирается связная дорожная компонента района; отсутствующие связи не заменяются прямыми линиями между кварталами.
3. В пределах контура выбираются 63 жилых, общественных и коммерческих здания. Гаражи, склады, навесы и стройки исключены.
4. Каждое здание соединяется с ближайшим подходящим проездом через точку проекции на дорогу. Ввод не пересекает другие здания; длина ввода ограничена 150 м. На месте ответвления создаётся узел.
5. Неиспользуемые тупики удаляются. Промежуточные вершины одной дороги объединяются в полилинии с сохранением изгибов. Каждый дорожный участок содержит `osm_way_id`, `route_kind` и имя дороги.
6. Остов дорожного графа задаёт штатные открытые участки; оставшиеся 68 связей — условные нормально закрытые резервы. Подача и обратка используют один коридор, визуально разделены в пикселях без смещения WGS84-геометрии.

Версия: `kostanay-yubileyny-1`. 538 узлов, 672 трубы, 672 условные участковые задвижки, 63 здания, 28 виртуальных датчиков. Длины рассчитаны из геометрии в локальной метрической проекции. Контуры зданий и адресные номера взяты из OSM; отсутствующие номера и население не выдумываются.

Источник — условный ввод на юго-востоке района. Диаметры, сопротивления, нагрузки и расположение арматуры — параметры демонстрационной модели. Для зданий принята нагрузка 0.10 кВт/м² площади контура, ограниченная диапазоном 20–200 кВт, без выдуманных этажности и числа жителей. Для рабочей инженерной модели нужны данные эксплуатирующей организации.

## Воспроизведение

```sh
uv pip install --python backend/.venv/bin/python -r scripts/requirements-geography.txt
PYTHONPATH=backend backend/.venv/bin/python scripts/build_kostanay.py
PYTHONPATH=backend backend/.venv/bin/python scripts/export_demo.py
```

Приложение загружает подготовленный файл `backend/app/data/kostanay-yubileyny-network.json` без сетевых запросов и без Shapely в runtime. На чистой базе эта модель устанавливается по умолчанию. Старая встроенная demo-1/demo-2 обновляется добавлением новой версии; исторические модели, расчёты и инциденты сохраняются. Пользовательская импортированная модель автоматически не заменяется. Архивный расчёт открывает свою версию сети через `GET /api/v1/network?version=...`.

Карта показывает реальные контуры зданий и OSM-ориентир района. Отключённые здания выделяются своими полигонами, без прямоугольной зоны поверх кварталов.

## Проверки

22 backend-теста, включая совпадение вершин и середины каждого дорожного сегмента с исходной OSM-линией с допуском 3 см, соответствие длин геометрии, расположение в Костанае, штатную связность всех зданий, гидравлическую допустимость и восстановление резервом. Старая квадратная модель сохранена только как отдельный контрольный fixture для аналитических и нагрузочных тестов.

Production-сборка и браузерные сценарии проверяют карту, расчёты, телеметрию, PDF и мобильную навигацию. Актуальные скриншоты: `design-network.png`, `design-simulation.png`, `design-telemetry.png`, `design-mobile.png`.
