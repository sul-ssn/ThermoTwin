# Статус относительно ТЗ

## Реализовано

- Каноническая версия сети; JSON/GeoJSON импорт, проверки ID, контуров, ссылок и структурной связности.
- Раздельные графы подачи/обратки; совместная достижимость потребителей.
- Изоляция участка, отказ арматуры, снижение граничного давления; переключение резервов, сравнение вариантов.
- Изолированные сценарии, сохранённые входы/состояния/снимки модели; аудит.
- Карта основных объектов, поиск, карточки, переключение слоёв, подсветка отключений.
- Телеметрия, WebSocket и polling; приём тестового источника.
- Ограниченная гидравлика, аналитический тест, статусы расчёта.
- PDF с параметрами, объектами, действиями, предупреждениями и схемой.
- RBAC: администратор / диспетчер / наблюдатель; OpenAPI, Compose, тесты.

## Не завершено для полной приёмки MVP

- Отдельные нормализованные предметные таблицы и миграции; PostGIS геометрии/индексы.
- Redis/Celery, асинхронный жизненный цикл задач, отмена и устойчивость к перезапуску worker.
- Физическая модель реальной арматуры и локализации; независимая инженерная проверка.
- Глобальный поиск оптимальных допустимых конфигураций с проверкой всех ограничений.
- Модули управления пользователями, хеширование паролей, лимиты входа, TLS reverse proxy.
- Архитектура русской/казахской локализации; камеры и насосные станции как самостоятельные сущности.
- Проверка Edge/Safari. Chrome desktop/mobile и HTTP-нагрузка из 10 параллельных клиентов проверены; это ещё не полный пользовательский нагрузочный профиль.
- Видео демонстрации и полный отчёт приёмки на зафиксированном сервере.

Реализация — рабочая демонстрационная основа, не заявление о выполнении всех критериев ТЗ.

## Проверки 10 октября 2026

- 18 backend-тестов: оба контура, общий источник, отказ/неизвестная/закрытая арматура, воспроизводимость, резерв, гидравлика, API, RBAC, PDF и телеметрия.
- 2 браузерных сценария Chrome: полный путь диспетчера и мобильный экран.
- Production-сборка Next.js и TypeScript прошли.
- Сеть demo-2: 1250 узлов, 1824 трубы, 312 потребителей.
- p95 вычислительного ядра: 62.62 мс (20 запусков).
- HTTP p95: 330.21 мс; при 10 одновременных клиентах: 942.55 мс.
- Стенд: macOS 26.2, arm64, Python 3.12.12, SQLite, два worker-процесса. Запуск frontend-сборки и pytest выполнялся параллельно HTTP-замеру; показатели не являются изолированным серверным бенчмарком.
- Docker Compose подготовлен, но не запущен: Docker отсутствует в локальной среде.

Точные замеры и условия: kpi-report.json / kpi-http-report.json.
